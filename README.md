# 🛒 ShopKart - E-Commerce Website

A full-stack E-Commerce website built with **Python, Django, HTML, CSS & SQLite**. 
Browse products, Add to Cart, update quantity & Place Order - Just like Flipkart!

**Live Project:** https://github.com/srikanya05/ShopKart-Ecommerce-Django

---

### ✨ Features
- 🏠 Home Page with all Products
- 🛒 Add to Cart functionality
- ➕ / ➖ Increase / Decrease Quantity
- 🗑️ Remove Item from Cart
- 💰 Automatic Total Price Calculation
- ✅ Checkout & Order Success Page
- ⚙️ Django Admin Panel for Product Management

### 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Tools:** VS Code, Git, GitHub
